WALLORA Control — сборка APK через GitHub Actions

1. Создай НОВЫЙ пустой репозиторий на GitHub, например WALLORA-Control.
2. Распакуй этот ZIP на компьютере.
3. Загрузи ВСЕ файлы и папки из распакованной папки в корень репозитория. ВАЖНО: папка .github тоже должна загрузиться.
4. Открой вкладку Actions.
5. Выбери workflow "Build WALLORA APK".
6. Нажми "Run workflow" -> "Run workflow".
7. Дождись зеленой галочки.
8. На странице запуска внизу будет Artifacts -> WALLORA-Control-APK.
9. Скачай ZIP, распакуй — внутри будет WALLORA-Control.apk.

AndroidForge больше не нужен.
